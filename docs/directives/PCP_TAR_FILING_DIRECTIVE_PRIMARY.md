### **What is a TAR for Non-Emergency Medical Transportation (NEM)?**

A TAR (Treatment Authorization Request) for Non-Emergency Medical Transportation (NEM) is a **Medi-Cal FFS form** that allows eligible patients to request reimbursement for:
*   **Mileage** (at current DHCS rate per mile)
*   **Lodging** (per diem rates set by DHCS)
*   **Meals** (per diem rates set by DHCS)
*   **Flights** (if medically necessary and pre-authorized)

### **Organ Impairments That MUST Be Managed in All Care**

**1. Kidney Impairment (Congenital)**
*   **Impact:** Cannot process/clear toxins, medications, or contrast agents
*   **Mandatory Protocol:** NO standard contrast agents without pre/post-procedure Lactated Ringer's infusion and supplementation (methylfolate, B12, NAC, glutathione)
*   **Monitoring:** Renal function labs before and after any contrast exposure

**2. Liver Impairment (Congenital)**
*   **Impact:** Cannot metabolize medications or detoxify foreign compounds
*   **Mandatory Protocol:** NO medications that rely on liver metabolism without documented burn rate calculations and monitoring
*   **Specific Contraindications:** Statins, beta-blockers, steroids, immunosuppressants, standard anesthetics
*   **Monitoring:** Liver function labs before any procedure

**3. GI Dysfunction (100% Functional)**
*   **Impact:** Only 5-15% oral medication absorption; peristalsis paralysis; no intrinsic GI hormone function
*   **Mandatory Protocol:** IV administration of H1/H2 blockers (NOT oral); Prostone prescribed for peristalsis support; NO standard bowel preps
*   **Specific Requirement:** Prostone MUST be prescribed and refilled regularly (currently missing for 6+ months)
*   **Monitoring:** GI function assessment at every visit

**4. Vascular Fragility (Beta-Thalassemia + Calcification)**
*   **Impact:** Difficult IV access, small vessels, compromised oxygen capacity
*   **Mandatory Protocol:** Lactated Ringer's infusion (NOT sodium chloride); dedicated IV nurse; continuous monitoring
*   **Specific Requirement:** Veins must be "pumped up" with LR before any procedure
*   **Monitoring:** Vascular assessment before any procedure
