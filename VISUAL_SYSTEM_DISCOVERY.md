# Visual System Discovery — Approval-Gated

## Scope and boundary

This working note records **observed interface patterns** from the user-referenced live UCM and Black Plum sites. It is not a license to copy their business content, make entity claims in the medical site, or change the medical site before approval. UCM and Eternal Autumn contexts remain separate from the medical-advocacy record system.

## Conflicts in the current medical site

The current medical site is too utility-dashboard-like. It relies on multiple bordered cards, verbose top navigation, a large pink sans-serif hero, and frequent status components. Those patterns do not match the observed reference sites’ editorial pacing, immersive image/texture treatment, serif-forward hierarchy, numbered pathways, or disciplined call-to-action count.

## Proposed restoration principles — not yet applied

1. Use **one distinct entry path** per page rather than a dashboard of equal-weight cards.
2. Use a serif display hierarchy and compact sans-serif operational text.
3. Shift from card grids to long-form, evidence-led document bands, timelines, and specimen-like source entries, with imagery only where the user supplies an appropriate, non-diagnostic source asset.
4. Keep medical evidence, uploaded records, and care-resource actions private and clearly separated from UCM/Eternal Autumn content.
5. Do not treat the existing color correction as approved; palette, type, imagery, and interaction rhythm require an explicit restoration decision.
